# Kuza Wellness Improved Streamlit Prototype

Run in the project folder:
1. Activate the virtual environment: `.venv\\Scripts\\activate`
2. Install requirements if needed: `pip install -r requirements.txt`
3. Start: `python -m streamlit run app.py`

The improved version clarifies the CHV role, consent and opt-out, strengthens the layout, and labels demo data. Facility names, waits, and slots are illustrative only. Do not enter real personal or medical information.
